# Sam's website
An umbrella site pointing to all my other projects and sites. 

# How it's built

- Simple HTML and CSS
- Hosted as a [public repo on Github](https://github.com/swoloszynski/samdw-website), hosted on Github pages connected to a custom domain at samduongwoloszynski.com
- [Cloudflare](https://www.cloudflare.com/) configured to redirect samdw.org to the longer URL
- Domains registered with [Namecheap](https://namecheap.com/)
- Contact form powered by [Letterbird](https://letterbird.co/)
- Calendar booking via Google Calendar on my personal email account
